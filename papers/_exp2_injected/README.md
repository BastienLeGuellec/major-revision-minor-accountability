# Altered manuscripts: not the published articles

Every file in this folder is a published CC BY-licensed article into which a language model has deliberately inserted one serious methodological or statistical flaw (Experiment 2 of the study). **The text does not describe the study as it was conducted or published.** Do not read, cite or reuse it as the original article; use the DOI in the file name to find the version of record.

The exact passage that was replaced in each file, and its replacement, are recorded in the `flaw_location` field of `../../results/exp2_injections.jsonl`.
